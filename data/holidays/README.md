# 공휴일 데이터

## 왜 파일로 분리했는가

대한민국 공휴일은 **계산으로 유도할 수 없다**:

1. **음력 기반** — 설날, 추석, 부처님오신날은 음력 날짜라 양력 변환이 필요하다.
2. **대체공휴일 규칙이 법 개정으로 바뀐다** — 2021년, 2023년, 2026년에 각각 확대되었다.
3. **임시공휴일은 그 해에 지정된다** — 예측 불가 (2024-10-01 국군의 날, 2025-01-27).
4. **공휴일 자체가 추가/삭제된다** — 제헌절은 2008년 제외 후 2026년 부활, 노동절은 2026년부터 법정공휴일.

따라서 코드에 하드코딩하면 매년 코드를 수정해야 하고, 잘못된 계산식은 **조용히 틀린 결과**를 낸다.
데이터로 분리하면 비개발자도 JSON을 갱신할 수 있다.

## 파일 형식

```jsonc
{
  "_meta": {
    "year": 2026,
    "verification": "확정" | "추정 — 반드시 재확인 필요",
    "note": "특기사항",
    "uncertain": ["불확실한 항목 목록"],   // 선택
    "sources": ["참고한 URL"]
  },
  "holidays": [
    { "date": "2026-01-01", "name": "신정", "type": "PUBLIC" }
  ]
}
```

### `type` 값

| 값 | 의미 | 영업일 계산 |
|---|---|---|
| `PUBLIC` | 법정공휴일 | 제외 |
| `SUBSTITUTE` | 대체공휴일 | 제외 |
| `TEMPORARY` | 임시공휴일 | 제외 |
| `COMPANY` | 사내 휴무일 (창립기념일 등) | 제외 |

`type` 은 표시·통계용 구분일 뿐이고, **영업일 계산에서는 네 종류 모두 동일하게 비영업일로 취급**된다.
사내 창립기념일이나 단체 연차 소진일이 있다면 `COMPANY` 로 추가하면 자동 반영된다.

## 갱신 방법

### 1. 신규 연도 추가

한국천문연구원이 매년 6~7월경 다음 해 「월력요항」을 발표한다. 발표 후:

1. `<연도>.json` 파일을 새로 만든다.
2. 아래 출처에서 날짜를 확인해 채운다.
3. `npm run db:seed` 실행 (기존 데이터는 날짜 기준 upsert 되므로 중복되지 않는다).

### 2. 기존 연도 수정 (임시공휴일 지정 등)

해당 연도 JSON에 항목을 추가하고 `npm run db:seed` 를 다시 실행한다.

### 신뢰할 수 있는 출처

- [한국천문연구원 음양력 변환](https://astro.kasi.re.kr/life/pageView/5) — 음력 기반 공휴일의 1차 출처
- [공공데이터포털 특일 정보 API](https://www.data.go.kr/data/15012690/openapi.do) — 프로그램으로 받아올 수 있음
- [관공서의 공휴일에 관한 규정 (국가법령정보센터)](https://www.law.go.kr/법령/관공서의공휴일에관한규정) — 대체공휴일 규칙의 근거
- [정책브리핑](https://www.korea.kr) — 임시공휴일 지정 발표

## 대체공휴일 적용 규칙 (2026년 기준)

| 공휴일 | 토요일 겹침 | 일요일 겹침 | 다른 공휴일 겹침 |
|---|---|---|---|
| 삼일절·광복절·개천절·한글날 | 적용 | 적용 | 적용 |
| 어린이날 | 적용 | 적용 | 적용 |
| 부처님오신날 | 적용 | 적용 | 적용 |
| 성탄절 | 적용 | 적용 | 적용 |
| 노동절 (2026년~) | 적용 | 적용 | 적용 |
| 제헌절 (2026년~) | 적용 | 적용 | 적용 |
| 설날 연휴 (3일) | **미적용** | 적용 | 적용 |
| 추석 연휴 (3일) | **미적용** | 적용 | 적용 |
| 신정 | 미적용 | 미적용 | — |
| 현충일 | 미적용 | 미적용 | — |

> 현충일은 추모일 성격상 토·일에 겹쳐도 대체공휴일이 없다.
> (2026년 6월 6일이 토요일인 사례로 확인)

## 데이터 부족 시 동작

롤링 윈도우(기본 18개월)가 커버하는 기간의 공휴일 데이터가 없으면,
그 기간의 영업일 계산이 **주말만 반영한 부정확한 값**이 된다.
대시보드 상단에 경고가 표시되므로 그때 이 디렉토리에 파일을 추가하면 된다.
